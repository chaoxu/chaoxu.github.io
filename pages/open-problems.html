Open problems

These questions remain open to my knowledge. Last status check: 20 November 2026. These are the only three combinatorial optimization problems I still care deeply about. Since the rise of AI, the problems I care about have been solved one by one. Once these are solved, I will probably take a long break and do something else. They are ordered below by how much I care about them, from most to least. Solved problems will be removed, and no history of this list will be maintained here.

Problem1Deterministic Exact Matching

Given a finite undirected graph G=(V,E), a set R⊆E of red edges, and an integer r, is there a deterministic polynomial-time algorithm deciding whether G has a perfect matching M with ∣M∩R∣=r?

Randomized polynomial time is known (see Sebő, p. 6).

Problem2Minimum submodular k-partition

For every fixed integer k≥6, is there a polynomial pk​ such that, given an arbitrary submodular function f:2U→R via a value oracle on an n-element set U with n≥k, one can partition U into k nonempty parts P1​,…,Pk​ minimizing ∑i=1k​f(Pi​) using at most pk​(n) oracle calls and arithmetic and comparison operations?

For background on fixed-k submodular partitioning, see Hirayama et al. (§7).

Problem3Global linear k-cut for fixed k

Fix an integer k≥2. Given a finite digraph G=(V,E) with ∣V∣≥k and no prescribed terminals, find a minimum-cardinality arc set F⊆E such that G−F has at least k strongly connected components. Is this problem solvable in polynomial time for every fixed k, with the polynomial’s degree allowed to depend on k, or is it NP-hard for some fixed k?

See my thesis (Definition 1.2 and Table 1.2).
