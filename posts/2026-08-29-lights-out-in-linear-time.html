Lights Out on a Grid in Linear Time


An r×s Lights Out board has N=rs cells. Assume r≤s. Given an arbitrary initial state, one can find a set of buttons that turns every light off, or determine that none exists, in O(rs)=O(N) operations over F2​. For an n×n board this is the advertised O(n2) bound, where n is the side length rather than the number of cells.

This algorithm applies to the standard rule in which a button flips itself and its horizontal and vertical neighbors. It does not apply to an arbitrary matrix merely because its nonzero pattern is a grid.

The algebra behind the algorithm is old. Martín-Sánchez and Pareja-Flores used light chasing to reduce a rectangular board to a system whose dimension is the width of the board [martin_two_2001?]. Barua and Ramakrishnan, followed by Sutner, described the row recurrence through binary Chebyshev polynomials and characterized the nullity by a polynomial greatest common divisor [barua_sigma_1996?,sutner_sigma_2000?]. The polynomial facts used below are Lemma 4.1 and Theorems 4.1 and 5.1 of Sutner. Goldwasser, Klostermeyer, and Ware developed the same Fibonacci-polynomial connection from the viewpoint of parity domination [goldwasser_fibonacci_2002?]. Zheng Wang’s implementation uses this structure to obtain the O(n2) bound. I have not found a paper that states the full arbitrary-right-hand-side running time explicitly. The result below is a direct algorithmic consequence of the known polynomial description.

1 Chase one row

Rotate the board if necessary and regard it as s consecutive rows, each containing r cells. Write the button pattern as x1​,…,xs​∈F2r​, and write the initial state as b1​,…,bs​∈F2r​. Let H be the adjacency matrix of the path Pr​, and set T:=I+H. The equations for row i are

xi−1​+Txi​+xi+1​=bi​,x0​=xs+1​=0.

Once the first row x1​ is fixed, every later row is forced:

xi+1​=bi​+xi−1​+Txi​.

Multiplication by T takes O(r) time, so a proposed first row can be chased through the board in O(rs) time. The only question is how to find the correct first row without trying all 2r possibilities.

2 The last row is one polynomial equation

Define the path polynomials by

F0​(t):=0,F1​(t):=1,Fj+1​(t):=tFj​(t)+Fj−1​(t).

If the right-hand side were zero and x1​=z, the recurrence would give xi​=Fi​(T)z. For a general initial state, chasing with x1​=0 produces a vector y depending linearly on b1​,…,bs​. The final boundary condition xs+1​=0 is therefore

Fs+1​(T)x1​=y.

Since T=I+H, define

c(t):=Fs+1​(t+1).

The first row must satisfy

c(H)x1​=y.(1)

Light chasing has reduced the rs equations to r equations. Treating (1) as an arbitrary dense system would still cost O(r3). Its coefficient matrix is not arbitrary: it is a polynomial in the path matrix H.

3 A path is a polynomial module

Let e1​ be the first standard basis vector. The vectors

e1​,He1​,H2e1​,…,Hr−1e1​

form a basis of F2r​. Indeed, Hje1​ has a 1 in coordinate j+1 and has no nonzero coordinate beyond j+1. The corresponding Krylov matrix is triangular with diagonal entries 1.

The characteristic polynomial and the minimal polynomial of H are both

μ(t):=Fr+1​(t).

Thus the map

Φ:F2​[t]/(μ)⟶F2r​,q(t)⟼q(H)e1​,

is a vector-space isomorphism. Reducing a polynomial modulo μ simply replaces it by another polynomial with the same action on a row. Write y​:=Φ−1(y) and x:=Φ−1(x1​). Equation (1) becomes the single polynomial congruence

c(t)x(t)≡y​(t)(modμ(t)).(2)

This is the whole algorithmic simplification. The dense first-row matrix has become multiplication by one polynomial in a quotient of F2​[t].

4 Solve the congruence

Let

g(t):=gcd(c(t),μ(t)).

Equation (2) has a solution if and only if g divides y​. If it does, write

c=gc′,μ=gμ′,y​=gy′.

Since c′ and μ′ are coprime, the extended Euclidean algorithm finds a polynomial u satisfying

u(t)c′(t)≡1(modμ′(t)).

Then

x0​(t):=u(t)y′(t)

solves (2). Every solution is of the form

x(t)=x0​(t)+μ′(t)h(t)(modμ(t)),degh<degg.

In particular, the space of quiet patterns has dimension degg, recovering the classical common-factor formula [sutner_sigma_2000?]. For the n×n board, the two polynomials are Fn+1​(t) and Fn+1​(t+1).

5 Running time

The initial chase that computes y takes O(rs) operations. The polynomial c can be generated modulo μ by the same recurrence in O(rs) operations. Converting between standard and Krylov coordinates takes O(r2) operations because the change-of-basis matrix is triangular. Polynomial gcd, extended Euclid, division, and multiplication take O(r2) operations with classical arithmetic. The final chase that reconstructs all rows takes another O(rs) operations.

Since r≤s, every O(r2) term is absorbed by O(rs). This proves the following statement.

Theorem1

For every r≤s and every initial state of the standard Lights Out game on an r×s board, one can find a solution or determine that none exists in O(rs) operations over F2​.

The input and an explicit output both contain rs bits, so this running time is optimal in the usual unit-cost model.

6 What survives beyond rectangles

The row recurrence does not require the cross-section to be a path. Let T be any linear operator on a w-dimensional vector space over a field F, and consider the repeated strip system

xi−1​+Txi​+xi+1​=bi​.

The same chase reduces the system to

Fs+1​(T)x1​=y.

This system is the Lights Out equation on G□Ps​ when T=I+A(G). Lights Out on Cartesian products has also been studied from the viewpoint of universal solvability [peters_cartesian_2017?]. If T has an explicitly available cyclic vector and its minimal polynomial is μT​, then the cross-section is again a copy of F[t]/(μT​), and the boundary equation is again one polynomial congruence. This includes path cross-sections and companion matrices. Circulant systems have a similar one-polynomial representation because a row is naturally a polynomial modulo tw−1, even when T itself is not cyclic. A fixed-width repeated strip is linear-time after constant-size preprocessing.

Every operator admits a rational canonical decomposition into cyclic modules. With that decomposition in hand, the boundary equation splits into one congruence for each invariant factor. Computing the decomposition of an unstructured operator may cost as much as the original dense linear algebra. The useful cases are those where the decomposition is already visible from the graph or recurrence. This observation does not immediately give a linear-time algorithm for three-dimensional grids, whose cross-section is itself a two-dimensional grid.

Uniform weights cause no difficulty over a field when the coupling between consecutive rows is nonzero. Constant horizontal, vertical, and diagonal coefficients give the same recurrence after rescaling, with a different family of path polynomials. Over a composite ring such as Z/kZ, polynomial gcd is no longer a complete solvability test, and one needs prime-power or Smith-form methods.

The method fails to give the same bound when the layers vary. If row i has its own operator Ti​, chasing still reduces the system to its first row, but the compatibility matrix is formed by a noncommutative product of transfer matrices. It can be an unstructured dense matrix. The same obstruction appears for an arbitrary assignment of coefficients to the edges and diagonal entries of a grid-supported matrix.

Zero forcing separates these two phenomena. A zero forcing set of size k reduces an arbitrary sparse system with m nonzero entries to a k×k core, with O(mk+kω) preprocessing and O(m+k2) time for each subsequent right-hand side [wang_zero_forcing_2022?]. On a grid, the first row is such a set. The O(rs) algorithm above is faster for a single solve because the uniform grid core is a polynomial in one path matrix. Without that extra algebraic structure, zero forcing still gives the reduction, but not the polynomial congruence.
